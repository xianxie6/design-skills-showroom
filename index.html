上手指南先安装，再这样用

安装 需要 Python 3

npm install -g ui-ux-pro-max-cli
uipro init --ai claude

在 Claude Code 里也可以装成插件：

/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
/plugin install ui-ux-pro-max@ui-ux-pro-max-skill

使用

  1. 装好后直接用大白话提需求，它会自动触发：帮我给山间温泉 SPA 做一个落地页，目标客户是周末从上海过来放松的白领
  2. 只想先看设计系统、不急着写代码，可以直接跑它的检索脚本：
    python3 .claude/skills/ui-ux-pro-max/scripts/search.py "beauty spa wellness" --design-system -p "雾山汤所"
  3. 把设计系统存下来，后面每个页面都按它来：加 --persist，会生成 design-system/项目名/MASTER.md；单页要例外，再加 --page "checkout"。
  4. 给老项目换皮：用 ui-ux-pro-max 把我现有的 React 应用改成 Minimalism & Swiss Style，保留组件结构和业务逻辑，只替换颜色、字体、间距这些 token

适合：不知道该用什么风格，想要稳妥、专业、符合行业习惯的结果。注意：它擅长选型，原创感要靠你在它的基础上再加。

Taste Skill

★ 101.7k

先定艺术方向和核心创意，再用真图搭页面，最后自己截图挑毛病

  • 基于 247 个精选网站的研究
  • 20 个设计方向，每次发 3 张
  • 从开放图库找真图并署名
  • 3 种宽度浏览器自查，最多返工 3 轮
github.com/Leonxlnx/taste-skill
案例演示可以直接点着玩

场景给老城区一家小咖啡烘焙坊「慢烘」做官网。它不会先套模板，而是先找出这家店独有的东西，再挑一个艺术方向。点下面三张方向卡，看同一家店的三种做法。

第 1 步 · 读需求，列出只有这家店有的东西

「巷子里的小烘焙坊，只卖自己烘的豆子。店主以前是印刷厂的排字工。」

排字工出身鼓楼西巷 37 号每周四烘豆手写烘焙记录本一次只烘 1.2 kg
第 2 步 · 从 20 个方向里发 3 张，挑一张

第 4 步 · 按宽度预览

实际运行时，图片会从 Wikimedia Commons、Openverse、大都会博物馆等开放图库里找，只用 CC0 / CC BY / 公有领域的图，并在页面上署名。这里为了演示，用插画代替。

第 5–6 步 · 浏览器自查

390px768px1440px
  1. 第 1 轮 · 截图，找出前三个问题
    1. 390px 下「慢烘」被挤成两行 → 字号跟着容器宽度缩放
    2. 左右留白不等（24 / 40px） → 统一边距
    3. 豆单价格没对齐 → 改成等宽数字
  2. 第 2 轮
    1. 首屏看不出是咖啡店 → 加一句副标题
    2. 标题上方出现英文小标签 → 删掉（典型 AI 味）
    3. 红色用了 4 处 → 只留给店名
  3. 第 3 轮 · 通过
    1. 没有严重问题，交付

以「活字印刷」方向为例。整个流程大约 30–45 分钟。

上手指南先安装，再这样用

安装 需要 Node 22+ 和 Chrome / Edge

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

在 Claude Code 里装成插件：

/plugin marketplace add Leonxlnx/taste-skill
/plugin install taste-skill@taste-skill

使用

  1. 需求里多给「只有你有的东西」，它会从这些素材里找创意：用 taste skill 给老城区咖啡烘焙坊「慢烘」做官网。店主以前是排字工，店在鼓楼西巷 37 号，每周四烘豆，有一本手写烘焙记录。
  2. 它会自己发 3 个方向并挑一个。你想自己选，可以说：先把三个方向给我看，我来选
  3. 做 Dashboard 或 App 界面也行（v2.1 起），它会走另一套更克制的规则：用 taste skill 做一个烘焙批次管理后台
  4. 改旧页面：它会先在真实浏览器里检查现有页面，再动手。

适合：官网、品牌页、作品集这类要有原创感的页面。注意：跑一次大约 30–45 分钟、几十万 token；有自己的照片就替换掉它找的开放图片。

安装

npx impeccable install

在项目根目录运行。它会识别你装了哪些 AI 工具（Claude Code、Cursor、Codex 等），问你装在当前项目还是全局。之后用 npx impeccable update 升级。

使用

  1. 每个项目先初始化一次，它会问你产品是给谁用的、什么语气，写进 PRODUCT.md：
    /impeccable init
  2. 命令格式是「命令 + 范围」：
    /impeccable audit landing
    /impeccable critique pricing
    /impeccable polish settings
  3. 也可以直接说人话：/impeccable 把首页这块 hero 重做一下，太像模板了
  4. 常用的命令可以固定成快捷方式：/impeccable pin audit 之后直接输入 /audit。

适合：已有项目，想一块一块地打磨。注意：它不会替你定方向，bolder 和 quieter 往哪边调要你来判断。

安装

npx skills@latest add emilkowalski/skills

一次装上全部 15 个。常用的几个：emil-design-eng（总规则）、animate、review-animations、improve-animations、animation-performance、break-ui、mobile-native、apple-design、prototype。

使用

  1. 做新动画：用 animate 给笔记列表的删除操作做一个动画
  2. 审查现有动画：用 review-animations 严格检查一下这个下拉菜单
  3. 全项目体检，拿到按优先级排好的修改计划：用 improve-animations 审查整个项目的动画
  4. 压测 UI：用 break-ui 拿极端数据测一下用户卡片和评论列表
  5. 网页在手机上像原生 App：用 mobile-native 检查移动端的点击高亮、100vh 和输入框缩放

适合：跟其他 Skill 叠着用，专门补动效和细节。注意：它不管整体视觉方向和页面布局。

安装 需要 Node 18+

npx skills add nutlope/hallmark -g

-g 表示所有项目都能用，去掉就只装在当前项目。要用浏览器检查和截图，还需要：

npm i -g puppeteer-core

再加上本机装好的 Chrome。没有它们也能跑静态检查。

使用

  1. 新做一页，它会发 3 个主题让你挑：
    /hallmark 给预约制茶室「一盏」做预约页，每天三席，每席最多四位
  2. 不想用现成主题，加一句 custom，它只按你的描述设计，检查标准不变。
  3. 改版旧页面（保留内容和功能，换设计系统和布局）：
    /hallmark redesign ./src/app
    只想换皮就说 keep the layout，只修 AI 味就说 polish。
  4. 只检查、不改：
    /hallmark audit ./index.html
  5. 单独跑 sloplint：
    node skills/hallmark/scripts/sloplint.mjs ./index.html --render

适合：落地页、预约页、商店页，以及有风险的改版。注意：输出的是单页 HTML/CSS，主要面向网页。
