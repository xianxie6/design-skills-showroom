# 设计 Skill 陈列室

GitHub 星数前 5 的 AI 设计 Skill，每个都配了一个可以直接点着玩的场景演示，以及安装和调用方法。

**在线查看：https://xianxie6.github.io/design-skills-showroom/**

![封面](cover.jpg)

| Skill | 演示场景 |
|---|---|
| [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | 同一句「做个落地页」，3 个行业生成 3 套设计系统 |
| [Taste Skill](https://github.com/Leonxlnx/taste-skill) | 同一家咖啡店的 3 个艺术方向 + 浏览器自查 |
| [Impeccable](https://github.com/pbakaus/impeccable) | 用命令把 AI 默认页面逐块修好，7 处 AI 味 → 0 |
| [Emil Kowalski Skills](https://github.com/emilkowalski/skills) | 4 个小交互的动效与细节对比 |
| [Hallmark](https://github.com/Nutlope/hallmark) | 茶室预约页的 3 种主题材质 + sloplint 检查 |

演示是按各 Skill 官方 README 描述的工作方式复刻的，用来说明能力，不是 Skill 的真实运行输出。星数为 2026-10-24 从 GitHub 读取。

整个页面是一个独立的 `index.html`，图片已内嵌，直接用浏览器打开即可。
